# Документация проекта

## Описание проекта

Автоматизированные UI и API тесты для интернет-магазина "Читай-Город".

Проект использует следующие технологии и синтаксис:

1. **Python**: Основной язык программирования для написания тестов.
2. **Selenium**: Библиотека для автоматизации взаимодействия с веб-браузером.
3. **Pytest**: Фреймворк для написания и запуска тестов.
4. **Allure**: Инструмент для генерации отчетов о выполнении тестов.
5. **Requests**: Билиотека для автоматизации API-запросов.

### Структура проекта

- `pages/` - Page Obect для UI-тестов
- `test/test_ui.py` - UI-тесты
- `test/test_api.py` - API-тесты
- `config.py` - настройкa WebDriver
- `pytest.ini` - настройки Pytest
- `requierements` - зависимости проекта
- `conftest` - зависимости проекта

### Форматирование кода

- Код форматируется в соответствии с PEP 8 (стиль написания кода на Python).
- Используются docstrings для документирования методов и функций.
- Все шаги теста размечаются с помощью `@allure.step` или `with allure.step` для улучшения читаемости отчетов.

## Инструкция по запуску тестов для формирования отчета Allure

1. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Для запуска только UI-тестов выполните команду:
```bash
   pytest -m "ui"

3. Для запуска только API-тестов выполните команду:
```bash
   pytest -m "api"

4. Для запуска всех тестов проекта выполните команду:
```bash
   pytest

5. Запустите тесты с генерацией отчета Allure:
   ```bash
   pytest --alluredir=allure-results
   ```

   Эта команда запустит все тесты и выведет отчет в браузере.

---

## Инструкция по просмотру сформированного отчета Allure

1. После завершения тестов, чтобы просмотреть отчет, выполните команду:
   ```bash
   allure serve ./allure-results
   ```
   Эта команда запустит локальный сервер и откроет отчет в браузере.

2. В отчете Allure вы увидите:

   - **Epic**: Общий раздел проекта.
   - **Feature**: функциональная область, например `Поиск`.
   - **Название теста**: Например, `Поиск книг по жанру`.
   - **Story**: Пользовательская история внутри функции.
   - **Шаги теста**: Последовательность действий в процессе тестирования.
   - **Результат**: Успешное выполнение или ошибка с указанием текста ошибки.
